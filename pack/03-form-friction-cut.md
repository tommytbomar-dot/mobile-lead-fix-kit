# Form Friction Cut
Goal: more completed leads, not more fields.

## Default local-service form (keep)

1. Name  
2. Phone (required)  
3. One need field (dropdown or short text): Repair / Install / Estimate / Other  

## Usually cut

- Company name (for residential)  
- Full mailing address (ask later)  
- “How did you hear about us?” on first contact  
- Essay-length message boxes  
- Account creation before submit  

## After submit

- Thank-you page with **click-to-call** backup  
- Auto-email or notification to a phone that humans answer  

## Test

Submit once yourself on mobile. If you wouldn’t finish it in a parking lot, cut fields.
