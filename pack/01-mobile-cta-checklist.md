# Mobile CTA Checklist (15 points)
**Spiel Ventures · Mobile Lead Fix Kit** · Personal/business use

Use on your phone (not desktop). Score Yes/No.

1. [ ] Business name visible without scrolling  
2. [ ] Primary action is Call, Text, or Book (not “Submit” / “Learn more”)  
3. [ ] Tap-to-call uses a real `tel:` link  
4. [ ] CTA button contrast is readable outdoors  
5. [ ] CTA still visible after soft scroll (sticky or repeated)  
6. [ ] Button label matches what happens next  
7. [ ] No competing 3 equally loud buttons  
8. [ ] Hours visible near CTA or in header/footer  
9. [ ] Service area mentioned above the fold  
10. [ ] Contact page reachable in ≤2 taps  
11. [ ] Menu doesn’t hide Call on mobile  
12. [ ] Popups don’t block Call for first-time visitors  
13. [ ] Emergency / after-hours note if you offer it  
14. [ ] Same phone number as Google Business Profile  
15. [ ] You tested on a real phone, not only Chrome device mode  

**Rule:** Fix Nos first. Three Yes upgrades often beat a full redesign.
